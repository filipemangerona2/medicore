# MediCore Urgent Pro — protótipo corrigido

Protótipo para demonstração técnica, não validado para uso assistencial.

## Publicar no Streamlit Community Cloud
1. Substitua `app.py` no repositório pela versão deste pacote.
2. Adicione `requirements.txt` na raiz do repositório.
3. No Streamlit Community Cloud, confirme branch `main` e arquivo principal `app.py`, e reinicie/reimplante.

## Teste local
`pip install -r requirements.txt`
`streamlit run app.py`

A fórmula de infusão é uma demonstração matemática, não uma recomendação clínica.
